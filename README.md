# 🏠 House Price Prediction

A Machine Learning web application that predicts house prices based on property features using **Python, Streamlit, and Scikit-learn**.

## 📌 Project Overview

This project predicts house prices based on multiple house features such as area, bedrooms, bathrooms, parking, furnishing status, and other property details.

The application provides **real-time price prediction** through an interactive web interface.

## 🚀 Features

✔️ Predict house prices instantly  
✔️ Interactive Streamlit web interface  
✔️ Real-time prediction system  
✔️ User-friendly UI  
✔️ Machine Learning powered predictions

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Joblib

## 📊 Input Features

The prediction is based on:

- Area
- Number of Bedrooms
- Bathrooms
- Stories
- Parking Space
- Main Road Access
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Preferred Area
- Furnishing Status

## 🧠 Machine Learning Model

This project uses a **Machine Learning Regression Model** trained on housing data to estimate house prices based on property features.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/House-Price-Prediction.git
```

### 2. Navigate to project folder

```bash
cd House-Price-Prediction
```

### 3. Create virtual environment

```bash
python -m venv venv
```

### 4. Activate virtual environment

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```
